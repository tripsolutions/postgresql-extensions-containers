# CNPG Postgres Extension Containers

A simplified approach to building and managing PostgreSQL extension containers for CloudNativePG.

This repository provides a streamlined solution for packaging PostgreSQL extensions into container images compatible with CloudNativePG. While inspired by the official [cloudnative-pg/postgres-extensions-containers](https://github.com/cloudnative-pg/postgres-extensions-containers) project, this implementation takes a heavily simplified approach, focusing on essential functionality and ease of use over comprehensive features.

## Key Differences

This project differs significantly from the official postgres-extensions-containers repository by:
- Using a more straightforward build process
- Reducing complexity in configuration and setup
- Focusing on core extension packaging capabilities
- Maintaining simpler directory structures and naming conventions

## Usage

Refer to the documentation in this repository for instructions on building and deploying PostgreSQL extensions with CloudNativePG.
